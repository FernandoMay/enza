# Three-minute demo script

1. Show the existing ENZA presentation and explain that the live store at enza.in is external to this repository.
2. Open the separate ENZA Movement Testnet demo. Choose the **sample** reusable bottle and show its pending order.
3. Select Stellar USDC, connect a funded Freighter Testnet wallet, inspect the exact destination, asset, amount and memo, and authorize. Show the server-confirmed order and Testnet transaction link. This step requires configured, funded Testnet accounts and has not been demonstrated by repository tests alone.
4. Choose the **demo** ENZA-hosted sound healing session and repeat checkout to show that the same payment path issues one unique demo ticket after confirmation. There is no live booking or ticket fulfillment integration.
5. Explain that vendor settlement is planned: allocations and payout authorization must be built and tested before claiming a real vendor payout. International expansion also requires country-specific on/off-ramp and compliance review.
